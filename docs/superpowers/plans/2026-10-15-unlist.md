# Unlist Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Unlist, a local-only app that tracks data broker listings, generates removal requests, and reminds the owner to recheck.

**Architecture:** One npm package with three folders. `shared/` holds pure TypeScript logic (types, zod schemas, status rules, templates, merge) with no I/O. `server/` is an Express API that reads `brokers.json` and reads and writes `data/data.json` atomically. `web/` is a React + Vite UI that calls `/api` through Vite's dev proxy.

**Tech Stack:** Node 20+, TypeScript, React 18, Vite 5, Express 4, zod 3, Vitest, supertest, @testing-library/react, jsdom, tsx, concurrently, react-router-dom 6.

**Spec:** `docs/superpowers/specs/2026-10-15-unlist-design.md`

## Global Constraints

- App name in UI header and `<title>`: `Unlist`.
- API binds to `127.0.0.1` port `3001`; Vite dev server on `5173`, proxying `/api` → `http://127.0.0.1:3001`.
- `npm run dev` starts both; `npm test` runs all Vitest suites once.
- Data file: `data/data.json` (dir gitignored), backup `data/data.json.bak`, temp `data/data.json.tmp`. Path overridable by env `UNLIST_DATA_DIR` (used by tests).
- Broker list: `brokers.json` at repo root, committed.
- Dates are ISO `YYYY-MM-DD` strings in **local** time. Never use `toISOString()` for dates.
- Stored statuses: `found | request_sent | removed | relisted`. Derived: `not_checked` (no record), `due` (removed and `recheckAt <= today`).
- Default `settings.recheckDays`: `90`.
- Methods: `web_form | email | phone | mail | id_upload`. Relist risk: `low | medium | high`.
- The app never sends email; it only copies text or opens a `mailto:` link.
- No network requests from the app other than to its own `/api` and links the owner clicks.

## Review Focus

1. **Timezone off-by-one** — at 11pm local, "today" must still be the local date. Pinned by `todayISO` test in Task 2.
2. **Broker removed from `brokers.json` but a record remains in `data.json`** — the orphan must not crash the merge, must not appear in the table, and must not be deleted from disk. Pinned in Task 4 (merge) and Task 6 (PATCH keeps orphans).
3. **Special characters in mailto** — names like `O'Brien & Sons`, newlines and `#` in the body must survive `encodeURIComponent`. Pinned in Task 3 (`mailtoLink`).
4. **Two saves in quick succession** (two tabs, fast clicks) — writes must be serialized so the second does not read a stale file. Pinned in Task 5 (concurrent `update` test).
5. **Profile with nothing filled in, or no address marked current** — the template must not print empty lines or "undefined". Pinned in Task 3.
